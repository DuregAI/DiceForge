# Стабильность беты и локальная админка

## Что добавлено

- Локальная админка `http://127.0.0.1:18081/`: поиск по имени/ID, уровень карты, пройденные уровни, дата обновления и подтверждение сброса выбранного игрока.
- Таблица SpacetimeDB `player_progress` хранит сводку прохождения. Игровой клиент видит только собственную запись; администратор использует существующую авторизацию CLI на стороне локального сервиса.
- Сброс касается только карты. Имя, аватар, обучение, опыт, предметы и настройки сохраняются. Новый идентификатор прохождения исключает применение результата старого боя.
- Сервер увеличивает эпоху сброса. Клиент записывает её вместе с очищенной картой, удаляет старое сохранение карты в PlayerPrefs и возвращается в меню через существующий механизм переходов. Ошибка записи не подтверждает сброс.
- Идентификатор подключения сохраняется между запусками. Эпоха привязана к этой identity; замена токена не оставляет новую регистрацию с чужим счётчиком сбросов. При недоступном сервере игра сохраняет локальный профиль и повторяет подключение.
- Это синхронизация сводки и административного сброса, а не полное облачное сохранение между устройствами. Прогресс боя и профиль по-прежнему сохраняются в браузере.

## Запуск

Основные файлы изменений:

| Файл | Назначение |
| --- | --- |
| `tools/admin-server.py`, `admin-index.html`, `admin-ui.js`, `admin-ui.css` | Локальный интерфейс, чтение базы и защищённый вызов сброса |
| `spacetimedb/spacetimedb/PlayerAdministration.cs` | Реестр, приватность строк, права администратора и эпоха сброса |
| `Assets/_Project/02_Integrations/SpacetimeDb/SpacetimeDbProgressSync.cs` | Сводка прохождения и применение серверного сброса |
| `SpacetimeDbLocalDevRuntime.cs` | Сохранённая identity и повторное подключение |
| `Assets/_Project/01_Gameplay/Progression/ProfileService.cs`, `PlayerProfile.cs` | Атомарный сброс карты и локальная эпоха |
| `Assets/Tests/Progression/ProgressionTransactionTests.cs` | Пять новых проверок сохранений и старых результатов |
| `spacetimedb/build-local.ps1`, `LocalWasi.targets`, `StdbModule.csproj` | Повторяемая сборка модуля без изменения старых бинарников |

Из корня Unity-проекта:

```powershell
python tools/serve-web-beta.py
python tools/admin-server.py
```

SpacetimeDB должен быть запущен на порту 3000, база — `diceforgelocaldev`.
Подробности сборки модуля: `spacetimedb/LOCAL_ADMIN.md`. Обновление добавляет таблицы и reducers без очистки существующей базы.

## Проверки и ограничения

Результаты запусков сохраняются здесь отдельно от предыдущих проходов. Сброс настоящего профиля пользователя не используется как проверка. Серверные проверки выполняются в отдельной локальной базе QA; проверки сохранений используют временный профиль и восстанавливают состояние Editor.

- Синхронный EditMode: 85 обычных NUnit-проверок прошли, ошибок нет. Пять новых случаев покрывают сохранение остальных данных, устаревший результат боя, ошибку записи, повторный сброс и смену identity. Многошаговые UnityTest этим запуском не выполнялись.
- Backend опубликован в существующую `diceforgelocaldev` без очистки. Существующие 7 отзывов сохранены. В отдельной `diceforgeadminqa` проверены RLS, запрет чужого сброса, права владельца, эпоха, сохранение имени, старое сохранение и повторный сброс. В основной базе проверка владельца использовала отсутствующего игрока и не изменяла данные.
- HTTP-защита админки: 9 проверок прошли, включая Host/Origin/CSRF и передачу 256-битной Identity без потери точности. Настоящий пустой реестр прочитан успешно.
- На сборке предыдущего прохода в браузере сыгран обычный матч до Victory. Карта открыла уровень 2 и показала 1/6; затем проверены пауза, отмена сдачи и подтверждённая сдача во втором бою. Скриншоты сохраняются здесь.
- Обновлённый release WebGL player собран успешно, ошибок нет, размер 95 200 827 байт. Итоговый `browser-build.txt` относится к повторному запуску из кеша (2,35 секунды, одно предупреждение), после завершения полной сборки; это не длительность полной сборки. MCP во время полной сборки достиг тайм-аута, сама Unity завершила сборку.
- На обновлённой сборке после перезагрузки сохранились язык, открытый уровень 2 и прогресс 1/6. Реальная строка игрока в админке показывает те же значения. Проверены поиск по ID, открытие подтверждения и отмена; сброс этого профиля не выполнялся. `admin-live-players.jpg`, `admin-confirmation.jpg`, `browser-map-after-reload.jpg`.
- Аудит готовой сборки подтвердил корректный WASM, строку Moving… без испорченной кодировки, загрузку русского шрифта и отсутствие пути загрузки китайского шрифта в метаданных. Отчёт `binary-audit.json`.

Ручная приёмка: имя игрока в списке; пройденный уровень после обновления страницы; открытие и отмена подтверждения сброса; сброс выбранного игрока во время боя и после повторного подключения.

SSAO и тени остаются отложенной задачей по решению пользователя. Удалённый сервер и публичная админка в этом проходе не разворачиваются.
