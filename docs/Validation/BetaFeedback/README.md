# Отзывы в бою и оценка после прохождения

- В настройках боя восстановлена кнопка «Отзыв». Общий блок действий раньше скрывался целиком; служебная кнопка копирования лога остаётся скрытой.
- В формах отзыва есть имя игрока, максимум 23 символа. При отправке оно атомарно сохраняется через существующий ProfileService. GUID и identity не меняются; отзывы и сводка в админке относятся к тому же профилю. Это существующий профиль браузера, а не новая регистрация или облачная учётная запись.
- После возвращения на карту с шестью пройденными уровнями предлагаются 1–5 звёзд, необязательный комментарий и «Позже». Показ проверяет именно все шесть авторских ID, а не количество произвольных записей.
- «Позже» откладывает предложение до следующего запуска страницы. После подтверждённой отправки окно больше не предлагается для этого прохождения; новый runId после сброса допускает новое предложение.
- Черновики обычного сообщения и оценки хранятся отдельно. Успех подтверждается только ответом Committed; ошибка и тайм-аут сохраняют текст и звёзды.
- Оценка поступает через существующий submit_feedback с category=rating и JSON message вида {"rating":4,"comment":"..."}. Схема базы не изменяется. В админке такие записи показываются звёздами и обычным текстом, без исполнения HTML.
- Окно реализовано отдельным PlayerFeedbackWindow: будущие переходы в wishlist/магазины можно добавить здесь. Сейчас оно отправляет только внутренний отзыв; внешние ссылки не подключены.
