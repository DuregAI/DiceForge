# Проверка оставшихся задач перед бетой

21 октября 2026. Проверяется текущий проект 0.4.3-release, Unity 6000.6 / URP 17.6.

## Что исправлено во время проверки

**Возврат из уровня мог оставлять в меню графический профиль леса.** `DioramaBoard` и `WoodlandHeroStage` оба запоминали и восстанавливали глобальный render pipeline. Если первым удалялся board, stage возвращал уже переопределённый HeroPipeline. Ошибка воспроизведена в `forest-lifecycle-before.xml` (1 Failed).

Теперь игровой pipeline принадлежит board; stage самостоятельно управляет им только в отдельном художественном просмотре без board. Регрессия проверяет оба порядка удаления компонентов и отдельный art stage. Новые правила игры и кадрирование не вводились.

Обновлён также устаревший помощник проверки интерфейса: он требовал вмещать все восемь плит на первом уровне, включая намеренно скрытые. Теперь проверяются все оставшиеся видимые плиты, с отдельным контролем их количества. Специальные проверки первого уровня продолжают требовать скрытия плит 0–3.

В художественном видеопросмотре отключён непривязанный к игровому полю mover двух демонстрационных моделей. Его предупреждения об отсутствующем BoardLayout не являлись ошибкой игровых героев.

## Небольшая художественная доводка — выполнено

В следующем проходе увеличены подписи и версия общих настроек, добавлены контактная пена и брызги водопада, заменены шесть ближних кустов. По новому решению пользователя Лума получила отдельный бирюзовый костюм через новый UV-атлас; прежний материал сохранён. Профиль и магазин остаются скрытыми.

Реальные кадры, исходники и результаты проверок: [Beta-v03](../LivingForest/Beta-v03/STATUS_RU.md). Большие задачи публичной беты выше остаются актуальными.
