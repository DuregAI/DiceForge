# Demo RC v0.1 — сюжет и обучение L1–L6

Источник: `03_LEVEL_SCRIPT_STORYBOARDS.md`, `04_DIALOGUE_TUTORIAL.md` и `data/dialogues.json` в `docs/DemoRC/v0.1`.

## Реализовано

- Импортируемый ScriptableObject-каталог: 138 авторских событий, 12 имён персонажей и семь комиксов по три кадра. Для S00/S04 используются исправленные листы v2. Арт остаётся без запечённых реплик; интерфейс показывает текст отдельно.
- Последовательность S00 → L1 → S01 → L2 → S02 → L3 → S03 → L4 → S04 → L5 → S05 → L6 → S06 с промежуточной картой кампании. Уже показанный переход не повторяется при первом входе в следующий уровень.
- «Дальше», «Пропустить сцену», повтор истории из справки. Комикс ждёт игрока без таймера и блокирует игровые действия. Завершение и награда ждут последнего движения и закрытия сюжетного перехода. После S06 результат сообщает о возвращении света и состоявшейся свадьбе.
- Типизированные условия учебных событий: выбор шага, именной герой, запрещённая посадка, реальный MoveRecord, независимый выход, остаток действий и движение/уступание Рыжа. Авторские строки условий не выполняются как код.
- Контекстная справка, закрытие одной подсказки и скрытие автоматического обучения. Режим сохраняется между уровнями. L1–L2 используют подпись «Совет Лумы»; L6 автоматически показывает только знакомую цель и конкретную причину неверного хода. Скрытие обучения не скрывает цель L6.
- Освоение засчитывается после реального изменения позиции/выхода и завершения анимации. Pass, пропуск текста, неверный ввод и повторное уведомление не добавляют доказательств. После трёх действий без помощи автоматические инструкции угасают.
- Ошибка дедуплицируется по состоянию, шагу и герою, с максимумом двух текстовых коррекций каждой причины за попытку. Уровневая реплика заменяет глобальную. Визуальный крест и текущая доступность остаются после лимита.
- Профиль хранит просмотренные события/сцены, навыки, режим помощи и данные текущей учебной попытки. Рестарт сохраняет знания и показывает короткую R02. Сохранение использует существующий атомарный механизм; при ошибке доступен повтор.
- RU-мастер отображается полностью. Для отсутствующего EN используется RU; пустые строки и внутренние ID не выводятся. Фактические EN-черновики из JSON сохранены в каталоге.

## Проверки

`learning-and-routes.xml`: 29/29 — правила, 12 эталонных маршрутов и семь проверок обучения/каталога.

`presentation-and-campaign.xml`: финальный повтор — 8/8. Сквозное прохождение L1–L6 и семь проверок обучения/каталога; режим скрытого обучения сохраняется между уровнями, цель L6 остаётся видимой. В консоли после завершения ошибок нет; редактор возвращён в MainMenu.

`regression.xml`: общий прогон — 124/127. Одна прежняя ошибка: `DioramaLightingIsSavedForEveryComposition`, у `FirstTrail8.prefab` отсутствуют сохранённые landscape/portrait lighting assets. Две другие ошибки были связаны с завершением тестового окружения (ответ SpacetimeDB после teardown и уничтоженный объект сцены).

`token-placement-recheck.xml`: отдельный повтор — 5/5, включая оба упавших теста размещения/анимации и загрузку обычных уровней 01/05/09. Хранилище профиля тестов изолировано с сохранением исходной идентичности игрока. Ошибки окружения не повторились; ошибка освещения остаётся открытой.

Сквозной тест использует временный профиль и проверяет все шесть уровней, однократность наград, чтение профиля с диска, правильный порядок семи сцен, блокировку ввода и отсутствие освоения/награды при пропуске. Комиксы дополнительно проверяются на попадание в границы UI-панели. Тесты размещения фигур также используют отдельное хранилище профиля.

## Что остаётся следующим этапам

Это интеграция сюжета и игрового обучения. Сохранение самой доски посреди уровня и восстановление checkpoint ещё не реализованы; учебный pendingHint не выдаётся за снимок доски. Портретные слоты поддерживают нейтральные спрайты, но новые финальные портреты пока отсутствуют — используется корректное имя персонажа. Окончательные модели/оформление мест, Рыж-NPC вне поля L6, музыкальная постановка, перевод сюжетного EN/ZH, настройка размера текста и приёмка на устройствах/в портретной ориентации остаются открытыми. Глобальные реплики, относящиеся к этим будущим функциям, импортированы, но не объявляются активными runtime-событиями.

WebGL-сборка, производительность устройств и длительность демо в этом этапе не измерялись.

## Повторить

Открыть MainMenu и проходить уровни через карту. Для повторного импорта: `Diceforge → Demo RC → Import story and dialogue`. Run EditMode: DemoCampaignFlowTests, DemoLearningTests, DemoCampaignTests, DemoHazardTests. Сквозной тест сам входит в PlayMode и восстанавливает прежний профиль/язык после завершения.
