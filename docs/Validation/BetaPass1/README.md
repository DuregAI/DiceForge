# Первый проход браузерной беты

## Изменения

- Служебные действия карты и переключение кошелька разработчика доступны только в Editor. Обычный браузерный player использует существующую игру без отдельного тестового режима.
- Адрес SpacetimeDB, имя базы и включение интеграции вынесены в `Assets/_Project/Resources/SpacetimeDbRuntimeConfig.asset`. Сейчас: `http://localhost:3000`, `diceforgelocaldev`.
- Отзыв считается отправленным только после подтверждения reducer со статусом `Committed`. Ошибка, отключение и тайм-аут сохраняют черновик. Пока отправка выполняется, поля и повторная отправка блокируются.
- Черновик сохраняется при редактировании. Браузерный шаблон включает автоматическую запись persistentDataPath в IndexedDB.
- При завершении игры отключение интеграции не создаёт заново уничтоженный модуль диагностики.
- Окно результатов допускает отсутствие корневого UI при проверке обработки ошибки сохранения.
- Форма отзыва в главном меню поднимается над окном настроек, из которого открывается.
- WebGL создаёт `SpacetimeDBNetworkManager` до конструктора соединения. Установленная версия SDK запускает парсер входящих сообщений через coroutine этого компонента; одного ручного `FrameTick` было недостаточно. В WebGL менеджер также выполняет `FrameTick`; на других платформах его вызывает игровой runtime.

## Проверки

- PlayMode: 22 проверки отзывов, модальных окон и переходов прошли.
- Синхронный EditMode: 80 обычных NUnit-проверок боя, размещения фишек и прогресса прошли; многошаговые UnityTest этим запуском не выполняются. Отчёт: `core-tests.xml`.
- SpacetimeDB CLI 2.10.2 установлен, локальный сервер доступен. База опубликована из существующего `StdbModule.wasm`, без очистки данных. Игра подключилась; проверочный отзыв получил `Sent`, SQL подтвердил одну запись.
- Результат production WebGL build сохраняется в `browser-build.txt`.
- Первая сборка: без ошибок, 28 предупреждений; размер около 108 МБ. Предупреждения относятся к устаревшим API, ассетам TMP, шейдеру и конфигурации Pipeline; это остаётся отдельной работой. В браузере главное меню загрузилось. Обнаруженный при запуске конфликт порядка окон отзывов исправлен.
- В браузере проверено восстановление текста черновика после обновления страницы. Финальная сборка получила подтверждение сервера, показала `Feedback submitted` и очистила поле. Скриншот: `browser-feedback.jpg`. Проверочные записи помечены `[BetaPass1 ...]`.
- Финальный release player собран с gzip: ошибок 0, предупреждений 28, размер 132 535 067 байт, сборка 1:25. Настройка сжатия проекта возвращена к исходному Brotli; предыдущий вариант Brotli занимал около 108 МБ и собирался дольше. Обе упаковки поддерживаются локальным HTTP-сервером.
- Неудачные и подключающиеся соединения тоже отключаются при повторной попытке; WebGL удаляет их из списка SDK manager, останавливая старый парсер.

## Локальный запуск

Из корня Unity-проекта:

```powershell
python tools/serve-web-beta.py
```

Открыть `http://127.0.0.1:18080`. Сервер отдаёт необходимые заголовки для gzip/Brotli и wasm. SpacetimeDB должен работать на порту 3000.

Для удалённого размещения нужно заменить адрес SpacetimeDB в asset и пересобрать player: localhost обращается к компьютеру самого игрока. Удалённый сервер в этом проходе не выбирался и не разворачивался.

Сценарии ручной приёмки: обновление страницы после изменения настроек/прогресса, отзыв при работающем сервере, отзыв при недоступном сервере с сохранением текста, повторное открытие формы, обычный матч без служебных кнопок.
