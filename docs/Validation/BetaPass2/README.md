# Второй проход браузерной беты

## Изменения

- По решению пользователя оставлены русский и английский. Переключатель циклически меняет только RU/EN. Старое сохранённое значение zh-Hans открывает английский.
- Русские тексты используют уже существующий RobotoSlab вместо большого китайского шрифта.
- NotoSansCJKsc-Regular.otf и .meta перенесены из Resources в docs/Archive/BetaExcluded/Localization. Переводы zh сохранены в JSON для возвращения языка позже.
- Неиспользуемые ресурсы Assets/TextMesh Pro сохранены с .meta в docs/Archive/BetaExcluded. Поиск GUID-зависимостей из Assets/_Project, Assets/Settings и ProjectSettings не обнаружил ссылок на них; игровой код не использует TMPro.
- Галочка переключателей паузы рисуется вектором и не требует символа из шрифта.
- Русским надписям главного меню выделено место рядом с декоративными значками.
- В BetaPassValidation добавлена сборка второго прохода с сохранением отчёта и сообщений Unity.

## Проверки

- Проверены RU/EN, полный цикл переключения и загрузка старого значения zh-Hans. Результаты: localization-check.txt. Проверка не меняет сохранённый язык Editor.
- В Editor подтверждены кириллица в RobotoSlab и отсутствие китайского шрифта в Resources; ошибок компиляции не обнаружено.
- В браузере проверены русское меню, настройки, форма отзыва, карта, игровой экран и сохранение выбранного языка после обновления страницы. Существующий черновик отзыва сохранён; дополнительный отзыв не отправлялся.
- Отдельно проверены метаданные готового player: корректный литерал Moving…, отсутствие повреждённого литерала и загрузки китайского шрифта, наличие загрузки RobotoSlab. Скрипт: tools/audit-web-beta.cjs, результат: binary-audit.json. Он проверяет кодовые ссылки на шрифты, а не наличие исходных файлов шрифта внутри сжатых Unity asset bundles.
- В финальной браузерной сборке проверено выключение/включение векторной галочки паузы; исходная настройка звука восстановлена. Скриншот browser-pause-ru.jpg.
- Это проверка встроенного Chromium-браузера на Windows. Safari и удалённое размещение в этот проход не входят.

## Размер и ограничения отчёта

Исходный отчёт baseline-assets.tsv показывает примерно 18 МБ упакованных ресурсов китайского шрифта и TMP до внешнего сжатия. Это размер ресурсов из предыдущего отчёта, а не измерение сетевой загрузки.

Предыдущая браузерная сборка: 132535067 байт с gzip. Финальная: 95227722 байта (95,23 МБ) с исходной настройкой проекта Brotli. Полная сборка: Succeeded, 0 ошибок, 22 предупреждения (full-build-observed.txt). Последующая инкрементальная проверка: Succeeded, 0 ошибок, 1 предупреждение (browser-build.txt); этот результат не означает устранение всех предупреждений полной компиляции. Сравнение общих размеров включает разницу способов сжатия; его нельзя целиком приписывать исключению шрифта.

Unity может возвращать пустой список packedAssets для инкрементальной сборки, в том числе с DetailedBuildReport. Такой список не означает, что в игре нет ресурсов. Пустой отчёт нельзя использовать для сравнения объёма ассетов.

Меши портретных и широких островов имеют одинаковое количество вершин, но различаются положениями вершин и bounds. Их не объединяли. Большие меши и атласы остаются следующими кандидатами на отдельную оптимизацию.

## Оставшиеся предупреждения

Финальная полная сборка сохраняет предупреждения исходного проекта, включая устаревшие Unity API. Их устранение требует отдельного изменения и не является результатом этого прохода.

- Pipeline без RuntimePipelineConfig отключается в player. Runtime игры использует существующую интеграцию SpacetimeDB.
- В браузере сохраняется предупреждение URP про неподдерживаемый/исключённый шейдер FSR и пропуск post-processing passes. При открытии боя дополнительно обнаружена ошибка отсутствующих ресурсов ScreenSpaceAmbientOcclusion. Рендеринг требует отдельного решения; этот проход не исправляет его.
- Причина проверена по исходникам установленного Core RP и через Editor API: IncludeAdditionalRPAssets.includeReferencedInScenes сейчас false. WebGL собирается только с URP_2D_Battle, хотя HeroPipeline, DesktopPipeline и MobilePipeline входят в зависимости сцен и используются при переключении профиля во время игры. Подготовлен точечный план: включить includeReferencedInScenes в Assets/Settings/UniversalRenderPipelineGlobalSettings.asset, сохранить asset через Editor API, проверить список четырёх RP-профилей, пересобрать и повторить проверку боя/меню на SSAO и FSR. Настройка пока не применялась. Пользователь решил отложить доработку теней; SSAO/FSR оставлены отдельной задачей рендеринга после текущего прохода беты.
- Unity CLI установлен переносимо в C:/Backforge/Tools/UnityCLI, но его подключение к Editor требует доступа за пределами песочницы. Автоматическая проверка разрешений сообщила об отсутствии кредитов и не выполнила действие. Настройки PlayerSettings через CLI не изменялись; сборка выполнялась через существующий Unity MCP.

## Локальный запуск

Из корня Unity-проекта: `python tools/serve-web-beta.py`. Адрес: http://127.0.0.1:18080/. Существующий локальный SpacetimeDB должен работать на порту 3000. Финальная визуальная приёмка оставлена пользователю.
