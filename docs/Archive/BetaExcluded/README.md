# Ресурсы, исключённые из браузерной беты

Сохранены исходные файлы и Unity .meta, чтобы исключение было обратимым.

- `Localization/NotoSansCJKsc-Regular.otf`: китайский шрифт, исключён по решению пользователя. В бете используются английский и русский; кириллица отображается RobotoSlab. Переводы zh в JSON оставлены для будущего восстановления.
- `TextMesh Pro`: старые ресурсы и примеры TMP. Проверка GUID-ссылок из Assets/_Project, Assets/Settings и ProjectSettings не нашла зависимостей. Код игры не использует TMPro.

Для восстановления TMP перенести папку и её .meta обратно в Assets. Для возвращения китайского языка перенести шрифт и его .meta в Assets/_Project/03_UI/MainMenu/Resources/Localization и восстановить обработку третьего языка и его USS-стили в MenuLocalization/GlimblehopMenu. Затем проверить импорт и новую сборку.
