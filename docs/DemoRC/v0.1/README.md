## Арт и данные

В `art/` сохранены 13 выбранных концептуальных листов: четыре листа всех двенадцати персонажей, два листа шести локаций и семь комиксов по три кадра. Для S00 и S04 в книгу включены исправленные версии `-v2`: Бум появляется при присоединении команды, янтарная линза не появляется до встречи с Клочем. Первые варианты сохранены для истории правок, но не включены в книгу.

- [Промпты, references и происхождение изображений](art/prompts.json). Генерация выполнена встроенным image_gen; CLI/API не использовались.
- [Спецификация уровней и эталонные маршруты](data/levels.json).
- [Спецификация диалогов, событий и условий](data/dialogues.json).
- [Отчёт проверки пакета](package_validation.json).

Концепты являются визуальными ориентирами. Для игровой сборки отдельно создаются модели, риги, анимации, портреты, UI и корректная геометрия. Число нарисованных камней не заменяет восемь логических клеток.

JSON не является готовым Unity-импортом; его условия пока описательные. В книге отдельно указаны подтверждённое состояние проекта, новые решения и задачи внедрения. Код, игровые ассеты и текущий баланс проекта не изменялись. Проверка будущей сборки и числового баланса проводится после реализации.

## Обновление материалов

Редактировать исходные главы и данные, затем запускать `build_design_book.py` bundled Python с reportlab, Pillow и pypdf. Скрипт собирает PDF, HTML, общий Markdown и отчёт. При новых изображениях обновить массив ART. Все даты/версия и названия остаются рабочими для последующего обсуждения.
