# User-supplied goblin animation — sprite adaptation

## Result

The Woodland map now uses WoodlandSpriteHeroPresenter instead of the 3D portrait presenter. The battle character is unchanged. The earlier 3D presenter and prefab remain available as a fallback, but are not instantiated by MapController.

The atlas contains 30 transparent 256 × 256 cells: 20 run frames sampled from the six-second video at its native 24 fps, and 10 initial standing/blink frames. Idle holds for two seconds and plays the short blink forward/backward. Run uses a 20-frame loop at 24 fps (0.833 seconds). SetMoving(bool, bool faceLeft) is ready for route movement; this task does not yet implement travel between map nodes. Normal map display plays idle, not constant running in place.

## Source assessment

- grok-video-690af12e-755c-4416-bfff-77a95f16da44.mp4: 544 × 544, 24 fps, 145 decoded frames; chosen for temporal continuity. Run source frames 49–68, idle 0–9.
- 1224182 (1).mp4: 544 × 544, 24 fps, 25 decoded frames, about one second. Inspected but not used; it advances through distinctly changing poses quickly.
- goblin_run_12frames_green_3x4.png: mixes standing and running poses and different angles; unsuitable as a single clean run loop without rearrangement.
- ChatGPT Image Sep 18, 2026, 03_33_47 AM.png: contains similar repeated poses and visible cell separators; not selected over the longer video.

The original generated footage changes facial expression and angle slightly. The chosen cycle minimizes the seam but is not a perfect artist-authored locomotion loop. The existing light outer outline is retained; it is part of the source artwork. Green background and partial-alpha green spill were removed locally. No new AI imagery was generated and originals were not overwritten.

## Reproduction

inspect_sources.py decodes local videos to contact sheets; analyze_cycle.py scores possible loop seams; export_sprites.py keys the selected frames, uses a common scale and vertical reference, tracks horizontal position, and writes the atlas plus animated WebP previews. It records source path/hash and frame indices in manifest.json.

Python uses the bundled Codex Python with PIL/numpy. imageio-ffmpeg 0.6.0 was installed separately under C:/Backforge/.tools/goblin-video; it is not a Unity dependency and is not bundled into the game.

ImportHeroSprites.cs runs explicitly through Unity CLI. It uses Sprite Editor data providers, checks CreateAndDeleteSprite capability, maintains existing name/GUID mappings, and imports 30 named sprites. Atlas settings: 2048 maximum, bilinear, no mipmaps, uncompressed RGBA, transparent-edge dilation, no CPU-readable texture. All frames share one 2048 × 1024 texture (~8 MiB uncompressed); a device-specific compression/performance pass remains future work.
