# Woodland campaign visual rollout

The nine numbered campaign maps use the diorama presentation through their existing `BattleMapConfig`, `GameModePreset`, `BattleLauncher` and `BattleRunner` path. Levels 01-06 share the hand-composed eight-cell `FirstTrail8.prefab`; the old generic level 01 field and 15-cell Woodland Hero field are no longer assigned to these campaign maps. Levels 07-09 retain their larger provisional woodland compositions. Experimental maps and separate standard modes are unchanged.

Early-level balance is authored in each level's `RulesetPreset` and `SetupPreset`: levels 01-03 start with 2 goblins per side, 04-05 with 3, and 06 with 4. Their board size is 8, home size is 2, and start cells are 0 and 7. Existing dice bags, turn rules, result flow and rewards remain in place.

The rebuilt red and blue goblins have separate scarf colors. The game HUD shows only the turn and scores, available move values, a short hint, reroll when permitted, and pause. The old debug presentation is hidden while the diorama HUD is active.

To inspect: open `Assets/_Project/06_Scenes/MainMenu.unity`, enter Play Mode, and launch any numbered level through the normal map. The repeatable editor command is **Diceforge → Woodland → Enable playable dioramas for levels 01-09**. For balance changes alone, use **Diceforge → Woodland → Use eight-cell trail for levels 01-06**. The full builder needs a clean edit-mode scene and the FBX sources generated by `build_goblin_candidate.py`.

Validation performed: levels 01-06 resolve to the same eight-cell diorama with matching cell IDs, rules and setup sizes; their saved counts are 2/2/2/3/3/4. Runtime launch and screenshot smoke checks passed for levels 01 and 06 after rebalance. Level 06 displays three visible goblins and a `4` stack counter on each starting cell. No battle error appeared while playing. Stopping Play Mode may still log SpacetimeDB and DiagnosticsRuntime shutdown errors from existing integrations. Full match progression, rewards, portrait composition and device performance remain for hands-on checking. Levels 07-09 are playable visual placeholders.
