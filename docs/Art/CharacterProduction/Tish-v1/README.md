## Зафиксированная внешность

Оливково-зелёная кожа с тёплым жёлтым оттенком, янтарные глаза, каштановый чуб, крупные уши с розовой внутренней поверхностью. Коралловый шарф, коричневая кожаная туника с крупными стежками, короткие штаны, устойчивые ботинки, небольшая дорожная сумка. Лицо и силуэт сверять с фронтальным изображением; мелкие стежки не должны превращаться в шумную геометрию.

След укуса находится только на **анатомически правом ухе**. На фронте это слева для зрителя, на спине — справа. Левое ухо цельное. Сзади уши имеют зелёную наружную поверхность; розовую внутреннюю чашу туда не переносить. Кто укусил Тиша, пока не установлено.

Сумка на правом бедре, ремень идёт от левого плеча. Узел шарфа сзади. Эти стороны — рабочая фиксация данного комплекта. Не зеркалить изображения и модель. Для этого кандидата принята стилизованная кисть с четырьмя пальцами всего: три пальца и большой. В исходном запросе листа было пять; итоговый образ и отдельный фронт закрепляют четыре. Это рабочее производственное решение, не отдельное пользовательское утверждение.

## Пропорции, опора и поза

Единица производства — метр; 1 Blender unit = 1 m. Для первого сравнения в Unity целевая высота до верхней точки волос — **1.25 условной игровой единицы**, как в существующем импортёре Тиша. Это ориентир кандидата до группового масштабирования на плите, а не окончательная ростовая линейка всей деревни.

| Ориентир | Доля полной высоты H |
| --- | --- |
| Плоскость подошв | 0.00 |
| Верх ботинка | около 0.17 |
| Разделение ног | около 0.24 |
| Пояс | около 0.39 |
| Плечо | около 0.56 |
| Подбородок | около 0.64 |
| Линия глаз | около 0.77 |
| Макушка головы без чуба | около 0.93 |
| Верх чуба | 1.00 |

Доли сняты приблизительно с фронта; они служат контролем силуэта при построении единой сетки. Не использовать небольшие расхождения иллюстрированных ракурсов как разные размеры одного тела. После первого блокаута получить действительно ортографические виды из одной 3D-модели и ими заменить рисованный лист для точных измерений.

Поза — нейтральная A-поза, руки примерно на 35° от корпуса, ноги раздельно, обе подошвы стоят на одной плоскости. Для rig выровнять стопы вперёд; на изображениях допустим небольшой художественный разворот носков. Центр корневого объекта находится между стопами на земле. В игровом prefab Y направлен вверх, +Z — вперёд; преобразование осей проверять при экспорте, не задавать компенсирующий наклон всему игровому объекту.

## Первая генерация в Tripo

1. Создать нового кандидата `tish_v01`, загрузив отдельный фронт. Лист ракурсов использовать для проверки, либо отдельные виды — только если выбранный режим явно поддерживает несколько видов одного объекта.
2. Получить и осмотреть форму до rig. Проверить спину, уши, ремень, ладони, зазор между руками и телом, отдельные ноги и подошвы. Не тратить этап анимации на сетку с очевидно неправильным лицом или слипшимися конечностями.
3. Сохранить исходный экспорт и параметры в `C:/Backforge/Tripo3D/work/tish_v01/`. Не перезаписывать единственный исходник после ретопологии.
4. Передать кандидата в Blender через DCC Bridge. Доработать геометрию, UV и материалы; только после этого завершать rig и веса.
5. Экспортировать FBX и текстуры для Unity, проверить в папке приёма. Назначение в игровой каталог — отдельный следующий этап.

Короткий запрос к модели:

> One warm stylized forest goblin, Tish, matching the reference exactly. Neutral A pose, full body, separate arms and legs, four digits per hand including thumb. Olive-yellow green skin, amber eyes, short chestnut hair, coral scarf, brown stitched leather tunic and sturdy boots. Bite notch only on anatomical RIGHT ear; LEFT ear intact. Satchel on RIGHT hip with strap from LEFT shoulder. Consistent rear anatomy, scarf knot at the back. Matte materials, clean animation-friendly topology, no scenery, no extra props, no baked lighting.

## Геометрия и материалы

Рабочий бюджет первого кандидата: 15–30 тысяч треугольников, 1–2 основных материала, текстуры до 2K с последующей проверкой 1K. Это ориентиры до профилирования WebGL, не доказательство производительности.

Локти, колени, плечи, таз и основание ушей должны сгибаться без провалов и острых заломов. Проверить пальцы, веки и уголки рта крупным планом. Группировать волосы в крупные пряди; не моделировать каждый волос. Стежки и мелкую фактуру по возможности передавать текстурами. Шарф, сумка и пряжки не должны растягиваться вместе с соседней рукой. Контакт подошв проверять по геометрии, а не по запасу `SkinnedMeshRenderer.bounds`.

Разделить Base Color, Normal и Roughness/Metallic по назначению. Base Color без нарисованных бликов и теней. Проверять цветовые пространства и направление normal map. Для URP smoothness = 1 − roughness; наличие текстур после переноса само по себе не гарантирует правильный материал. Металл только на пряжках; кожа, ткань и волосы матовые.

## Скелет и набор движений

Первый маршрут — Generic rig на едином скелете. Humanoid пробовать отдельно и принимать только после проверки коротких ног, широких плеч и кистей. Корень между стопами; root motion выключен: положение на поле задаёт игровая логика.

| Клип | Содержание и проверка |
| --- | --- |
| Idle | Спокойное дыхание, редкое моргание; обе стопы устойчивы, нет постоянной тряски головы |
| Walk | Контакт стоп и перенос веса, короткий уверенный шаг; длительность согласовать с игровым перемещением |
| Jump | Подготовка → отрыв → полёт; движение вверх по игровой траектории не дублируется смещением корня клипа |
| Land | Сначала контакт подошв, затем мягкое сгибание коленей и восстановление; без проваливания в плиту |
| Selected | Короткий внимательный взгляд или наклон корпуса без смещения стоп |
| Victory | Радость в характере Тиша; сохраняется опора и читаемый силуэт рядом с другими героями |

Имена должны соответствовать реальным разным движениям. Idle и Walk — циклические; Jump, Land и реакции — отдельные фазы. Проверить стык первого/последнего кадров циклов, скольжение стоп и смешивание клипов. Полёт, приземление и скорость ходьбы привязывать к фактической длительности действия в игре, а не к произвольному фиксированному времени из генератора.

## Проверка первого кандидата в Unity

- Лицо, уши, шарф и сумка совпадают с эталоном с трёх сторон.
- Модель хорошо читается с настоящей игровой камеры и при трёх героях на плите.
- Обе стопы стоят на поверхности, pivot не сдвигается между клипами.
- Нет второго управления Animator и двойного root motion.
- Нет розовых материалов, случайного глянца и чрезмерно тёмного лица.
- Сохранения, ID `tish`, правила перемещения и активный каталог не меняются на этапе приёма.

var animator = tish.GetComponentInChildren<Animator>();
