# Финальная фактура персонажей · v01

Scratchy получил льняные и ржавые пряди вместо общей оранжевой доминанты,
более спокойные розовые щёчки, лёгкий рельеф плетения и локальный латунный
материал существующего бубенчика. Оливковые листья и шарф сохраняются.
У Тиша, Лумы и Бума цветовые атласы не изменены: добавлен сдержанный
микрорельеф существующих швов ткани и кожи. Лицо и живая кожа исключены
из основной маски рельефа. Каменная правая рука Бума остаётся матовой.

Два материала на персонажа сохранены: тело и глаза. Карта Scratchy задаёт
metallic через красный канал и smoothness через alpha. В URP Lit значение
alpha умножается на `.19`: мешковина около `.095`, пряжа `.110`, ботинки
`.175`, грубая латунь `.190`; глаза всех персонажей остаются `.52`.

Применение после компиляции Unity:

```csharp
Diceforge.Editor.CharacterFinishSetup.Apply();
```

Меню: `Diceforge/Characters/Apply character fabric finish`.
Команда обновляет существующие общие материалы, не меняя префабы,
профили поведения, анимации, blendshape, меши или риги. Портреты 2D,
наряд Лумы, контуры ушей и каменная рука не заменяются.

Импорт: цвет 2048, normal/surface 1024, mipmaps + trilinear, anisotropic 2,
HQ compression; текстуры недоступны CPU после импорта. Карты рельефа и
поверхности импортируются в linear. Цвет сохраняется в sRGB.

`scratchy-before.png`, `scratchy-after.png`, `scratchy-face-after.png` —
**Blender** A/B при одинаковом свете, не кадры из Unity. Финальную Unity
проверку и Web-сборку проводит основной агент после применения команды.

Воспроизводимая подготовка (все изменения только в текстурах):

1. Blender 5.2: `--factory-startup --background --python inspect_scratchy.py`.
   Извлекаются UV/координаты из production master `cast_v05/sources/Scratchy_polish.blend`.
2. Python с Pillow и NumPy: `bake_scratchy_finish.py`, затем `bake_cast_surface.py`.
3. Blender 5.2: `--factory-startup --background --python render_scratchy_finish.py`.
4. Применить `CharacterFinishSetup.Apply()` в Unity и проверить четыре героя.

Промежуточные `scratchy-uv-world.json.gz` и `scratchy-components.json`
создаются первым шагом. Они не являются runtime-ассетами и не нужны для
применения готового набора. Отчёты фиксируют источник и отсутствие
геометрических изменений; художественное утверждение они не подменяют.
