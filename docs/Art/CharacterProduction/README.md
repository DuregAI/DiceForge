## Что уже подключено

`Assets/_Project/Resources/DemoRC/Characters.asset` — общий каталог Тиша, Лумы, Бума и Царапа. Все шесть уровней берут игровые prefab из него, диалоги — закреплённые за героями портреты. Новая модель заменяется в одном месте. `productionApproved` пока false у всех: это честный статус художественной проверки, а не запрет играть.

Царап: маленькая живая кукла из мешковины; янтарные глаза, розовые швы на щеках, волосы из кремовых/рыжих/оливковых лоскутов с листьями, оливковый шарф и один латунный бубенчик. Это обязательные признаки во всех изображениях и модели. Исходный пользовательский референс: `scratchy-user-reference.png`; чистый полный рост: `Assets/_Project/07_Art/Characters/Scratchy/scratchy-profile.png`. На поле сейчас временная плоская фигура, не финальная 3D-модель.

Остальной состав сверять с `docs/DemoRC/v0.1/art/cast-01-heroes.png` и текущими диалоговыми портретами. Не генерировать каждого героя в новом независимом стиле. Английские имена существующего проекта сохранены: Tish / Jo / Boom; новый герой — Scratchy.

## Использовать уже купленную подписку Studio

1. В Tripo Studio загрузить чистый референс одного героя. Для Царапа использовать `scratchy-profile.png`, без других героев и фона.
2. Проверить силуэт до текстурирования: большая голова, короткие конечности, читаемые кисти и ступни; сохранить шарф и бубенчик. Исправить слипшиеся руки/ноги и лишние детали. Заднюю сторону единственный исходный ракурс не задаёт — её нужно проверить отдельно.
3. Сделать retopology, rig и анимации. Для первого игрового экспорта нужны Idle и Walk; затем отдельные Jump, Land, Selected, Victory. Анимации на месте, без перемещения корня. Idle/Walk зациклены, реакции — нет.
4. Экспортировать rigged FBX с текстурами. Сохранить исходный GLB/FBX вне сборки; рабочую версию положить в `Assets/_Project/07_Art/Characters/Source/<Hero>/`. Если клипы выгружены раздельно, сначала объединить их на одном скелете в Blender: текущий импортёр ожидает клипы внутри выбранного FBX.
5. В Unity выбрать FBX. Вкладка Rig: корректный Generic rig; Animation: клипы с именами Idle, Walk и доступными дополнительными состояниями. Материалы привести к URP/Lit, проверить base color, normal map, roughness→smoothness и отсутствие розового шейдера.
6. Меню `Diceforge > Characters > Import selected rigged FBX > Scratchy` (либо другой герой). Импортёр проверит skin и Idle/Walk, создаст отдельный controller/prefab, выключит root motion, выставит размер и положение ступней, заменит ссылку в каталоге. Исходный prefab не перезаписывается; созданный остаётся кандидатом.
7. `Diceforge > Characters > Audit active character catalog` запишет `docs/Validation/ScratchyDemo/character-audit.txt`. Проверить новую модель на уровне, в прыжке и рядом с другими героями, затем отметить одобренной в каталоге.

Этот путь не требует API-ключа. Подписка Tripo Studio и Tripo API используют разные кредиты: [официальное объяснение](https://www.tripo3d.ai/help/api-plugins/tripo-studiotripo-api).

## Подключение генерации к агенту

В установленном **MCP for Unity уже есть Tripo-провайдер** (`generate_model`, image/text input). Дополнительный MCP для базовой генерации не требуется. На момент проверки провайдер отвечает `configured: false` — ключ не введён. Генерация и списание API-кредитов не запускались.

Если нужен именно API: создать ключ в [Tripo API](https://platform.tripo3d.ai/api-keys), открыть в Unity `Window > MCP for Unity > Toggle MCP Window`, вкладку **AI Asset Generation**, включить Tripo, ввести ключ и сохранить. Ключ хранится через системное защищённое хранилище редактора. В чат, git и игру его не помещать. Refresh проверяет наличие ключа, а не платёжный баланс или успешность API-запроса. После этого агент может запускать задания; скелет, экспорт анимаций и художественная приёмка остаются отдельными этапами.

Есть также официальный [Tripo MCP](https://github.com/VAST-AI-Research/tripo-mcp) для Blender, но для текущей связки он дублирует часть установленной интеграции. [Официальные плагины Unity/Blender](https://developers.tripo3d.ai/en/docs/plugins) тоже требуют API-ключ. Если нужен их собственный интерфейс: Unity ZIP распаковать и добавить пакет из папки с `package.json`, затем открыть `Tools > Tripo API Unity`; Blender ZIP установить через Preferences > Add-ons > Install from Disk и включить, панель `View3D > Sidebar > Tripo 3D`.

## Художественная и техническая приёмка

Первый приоритет — закончить одного героя полностью, затем применять те же настройки к остальным. Начать с Царапа либо улучшить уже имеющегося Тиша, не генерировать всю команду без проверки одного экспорта.

| Проверка | Цель для первой качественной версии |
| --- | --- |
| Узнаваемость | Одинаковые пропорции, лицо, одежда и основные цвета в портрете и модели |
| Масштаб | Тиш/Лума около 1.25, Бум 1.65, Царап 1.05 условной единицы до группового уменьшения на плите |
| Материал | Мягкие матовые ткани и кожа; металл только там, где он есть; без нарисованных бликов и света в albedo |
| Геометрия | Начальный ориентир 15–30 тысяч треугольников на героя; окончательный лимит после профилирования целевого WebGL |
| Текстуры | Начать с 2K и 1–2 материалов; проверить результат при уменьшении до 1K и на мобильном экране |
| Rig | Ступни не скользят, локти/колени не ломаются, шарф и волосы не выворачиваются |
| Анимация | Idle, Walk, Jump, Land, Selected, Victory; настоящее движение, а не несколько названий одного Idle |
| Управление | Перемещение выполняет BoardLayoutTokenMover; GoblinLife единолично управляет Animator; root motion выключен |
| Интерфейс | Тот же портрет и имя на всех экранах; читаемый силуэт даже рядом с двумя другими героями |

Импортёр не делает автоматическую ретопологию, авторский rig, PBR-конверсию или художественное одобрение. Сейчас Тиш ~51.9k треугольников, Лума ~32.8k, Бум ~30.6k; у Лумы/Бума ряд реакций переиспользует Idle. Это очередь дальнейшей работы, не готовая финальная графика.

## Происхождение нового портрета

Создан встроенным imagegen по пользовательскому референсу; прозрачный фон. Запрос: один полный рост, почти фронтальный лёгкий поворот, руки отдельно от тела, обе ступни видны, спокойная улыбка; сохранить мешковину, лоскутные волосы, оливковый шарф, латунный бубенчик и янтарные глаза. Исключить фон, других персонажей, надписи, свечение и частицы; нейтральное освещение. Портрет служит интерфейсным ассетом и исходником image-to-3D, не подтверждает качество будущей геометрии.
