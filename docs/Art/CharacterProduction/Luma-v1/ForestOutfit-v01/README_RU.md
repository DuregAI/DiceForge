# Костюм Лумы: Forest Outfit v01

Бирюзовая ткань, узкая льняная кайма и приглушённый ягодный платок. Кожа лица и рук, волосы, глаза, уши, ремни, сумка и обувь сохраняют исходный образ. Это новый Base Color на существующей UV-развёртке; FBX, скелет, семь лицевых форм и семь клипов не переэкспортировались.

## Как менять костюм текстурой

1. За основу брать исходную развёртку `Luma_BaseColor_2K.jpg`, а не фотографию ткани или изображение персонажа. Текстура должна точно совпадать с UV модели.
2. В Blender открыть [Luma_ForestOutfit_v01.blend](Luma_ForestOutfit_v01.blend). Полный риг, карты и исходные узлы материалов упакованы в файл. `face-mask.json` отмечает поверхности одежды; `HairPolish` исключает волосы. Материалы `Teal linen` и `Berry scarf` содержат цвет, ткань и защиту исходных кожи/металла. Ткань получена через imagegen; её исходник — `Linen_Ivory_Source.png`.
3. Для другого цвета изменить материалы в `bake_outfit.py`, запечь Emit в ту же развёртку. Запекаются только поверхности одежды, фон атласа копируется из исходника. Параметр `use_clear=False` обязателен: очистка изображения уничтожит лицо и волосы. После запекания проверить спереди, сзади, сбоку, отдельно шею, пряди и границы ремня.
4. В Unity импортировать PNG как Default / sRGB / 2048 / Mip Maps. Назначить его в Base Map копии материала `Luma.mat`. Для текущего варианта это `Luma_ForestOutfit.mat`.
5. Назначить материал в `Resources/Characters/Presentation/Luma.asset → Body Material`. Этот профиль применяет один образ в игре и диалогах. Меню `Diceforge → Characters → Tripo → Apply Luma forest outfit` обновляет также сохранённые материалы трёх prefab.

Текущий игровой атлас: `Assets/_Project/07_Art/Characters/Incoming/Tripo/Luma_v02/Luma_ForestOutfit_BaseColor_2K.png`.

Исходные `Luma.mat` и JPEG сохранены. Для возврата назначить `Luma.mat` в Body Material профиля. Глаза используют отдельный материал и остаются прежними.

Перекраска меняет цвет, рисунок, ощущение ткани и отделку. Для рукавов, другого подола, накидки или нового силуэта нужно менять геометрию, UV и при необходимости веса. Текстура сама этого не создаёт. Выбор нарядов в интерфейсе не добавлялся.
