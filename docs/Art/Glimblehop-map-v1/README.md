# Glimblehop map — step 1 composition prototype

`01-layout-landscape.png` is a flattened concept mockup generated with the built-in imagegen tool. It is not an implemented Unity screen, layered asset pack, or 3D model. No game logic or saves were changed.

Six numbered levels form a single sequence. Levels 1–2 are completed, 3 is available with the static hero, and 4–6 are locked. The title, progress counter, and primary action are visible together. All six numbers and state badges were visually inspected in the generated output. Touch sizes and responsive behavior still require an interactive prototype.

The foreground bridge is scenery, outside the playable route. In subsequent background production keep it clearly decorative, or remove it if it suggests an alternative route. Reduce small foliage details at mobile scale. This landscape composition does not establish the portrait layout.

Next: lock platform anchors and route, then produce a clean background and separate platforms, badges, text, controls, and hero. Never import this flattened image as the final interactive map.
