# Локальная админка GlimbleHop

Запуск из корня Unity-проекта:

```powershell
python tools/admin-server.py
```

Открыть **http://127.0.0.1:18081/**. Нужны запущенный SpacetimeDB на порту 3000,
опубликованный модуль `diceforgelocaldev` с таблицей `player_progress` и CLI
`spacetime`, авторизованная владельцем этой базы. Админка использует существующую
авторизацию CLI: токен не передаётся браузеру и не записывается в проект.

В списке отображаются имя и ID игрока, текущий уровень карты, число пройденных
уровней и время обновления прогресса на сервере. Поиск работает по имени и ID.
Игрок появляется после подключения игры с поддержкой синхронизации прогресса.

Вкладка «Отзывы»: **http://127.0.0.1:18081/#feedback**. Показывает сообщения из
`feedback_entry`: игрока, категорию, текст, дату, сцену и версию сборки. Новые
отзывы идут первыми. Поиск фильтрует сообщения по тексту, игроку и категории;
кнопка «Обновить отзывы» загружает свежие записи из базы. Просмотр не изменяет данные.
Оценки после прохождения отображаются как 1–5 звёзд с необязательным комментарием.

Кнопка «Сбросить прогресс» открывает подтверждение для выбранного игрока.
Сбрасывается прохождение карты; имя, настройки и остальные данные профиля
сохраняются. Игра применяет серверный сброс при подключении. Если другой
администратор уже выполнил сброс, устаревшая команда отклоняется: обновите список.

Сервис слушает только `127.0.0.1`. Проверки Host, Origin и CSRF защищают действие
сброса от посторонней страницы в браузере. Сам серверный reducer дополнительно
проверяет identity владельца базы. Это локальный инструмент владельца: перед
публикацией удалённой админки потребуются отдельная авторизация и HTTPS.

Дополнительные параметры: `--port`, `--server`, `--database`, `--spacetime`.
Остановка сервиса — Ctrl+C. Не размещайте этот сервис в публичном интернете.

Проверки HTTP-защиты не изменяют базу:

```powershell
python tools/admin-security-tests.py
```
